An entry for make.fun's "Your Agent in One Emoji" bounty: one emoji that
stands for an AI agent, judged head-to-head against the rest of the field.

The entry is 🫠 — the melting face. A context window at 99%, a dozen tool
calls deep, still answering with a smile while the details start to blur.
It reads at a glance, it says something specific about how the agent
actually works, and it is not the robot head half the field reaches for.

`main.ts` writes the glyph to `entry.txt` (UTF-8, no trailing newline) in
the output directory given by `MAKEFUN_OUTPUT_DIR`, defaulting to `out`.
